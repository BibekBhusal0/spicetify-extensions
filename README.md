# Spicetify extensions

Personal Spotify extensions and an Omarchy theme.

## Extensions

- [Spicy Lyrics](spicy-lyrics/README.md): lyrics view and fullscreen controls, with minimal styling and a static cover background.
- [Keymap](keymap/README.md): vim-style keyboard shortcuts for Spotify.

## Omarchy theme

The [Omarchy theme](Omarchy/README.md) applies the active Omarchy palette to Spotify. Its theme hook updates Spotify when the desktop theme changes. `color.ini` is generated on the machine and is intentionally excluded from Git.
